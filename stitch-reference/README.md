# Stitch reference — PasteScribe

Exportação visual recebida do Google Stitch, reorganizada e compactada em `pastescribe-stitch-export.zip`.

Extraia localmente com:

```bash
bash scripts/extract-stitch-reference.sh
```

## Uso permitido dentro do projeto

- referência de composição e direção visual;
- inspeção de HTML e tokens;
- comparação visual durante a reconstrução;
- documentação de intenção.

## Não é código de produção

Os HTMLs podem conter estruturas, dependências e decisões inadequadas para a arquitetura final. Reconstrua os componentes no stack definido após a Onda 0.

Veja `docs/STITCH_REFERENCE.md` para regras completas.
