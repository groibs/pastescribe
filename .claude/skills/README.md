# Skills locais do PasteScribe

Criadas na Onda 0 (2026-08-03), adaptadas dos padrões pesquisados em `groibs/ressoa` e `groibs/rezenhai-mvp` (ver `docs/RESEARCH_REPORT.md` §1), sem identidade/copy dos produtos de origem.

## Ativas

| Skill | Quando usar |
|---|---|
| `pastescribe-scope-budget-delivery` | Início de toda tarefa média/grande; decide admissão e linha de corte mergeável |
| `pastescribe-ai-cost-governance` | Antes de qualquer chamada de IA, quota, orçamento, ledger, provider |
| `pastescribe-upload-url-security` | Qualquer código de URL externa, fetch, upload, FFmpeg, storage |
| `pastescribe-pre-merge-check` | Ao finalizar qualquer mudança, antes de PR |
| `pastescribe-ui-premium` | Redesenho/refino de qualquer tela; tokens e anti-AI-slop |
| `pastescribe-accessibility-review` | Toda tela/componente novo ou alterado (WCAG AA bloqueante) |
| `pastescribe-seo-international-check` | Rota pública, robots/sitemap, metadata, analytics |
| `pastescribe-feature-backlog` | Ideia nova, retomada de feature adiada, pausa de escopo |
| `pastescribe-product-simulation` | Antes de dar fluxo como pronto; jornadas reais + estados adversos |

## Adiadas deliberadamente (criar quando a onda chegar, com conteúdo real)

- `pastescribe-visual-polish` e `pastescribe-delight-motion` — dependem de UI real existente (Ondas 1.2/6/10); criar junto com os primeiros componentes para não nascerem genéricas;
- `pastescribe-ux-lab` — o núcleo (jornadas/personas) já está em `pastescribe-product-simulation`; separar quando houver pesquisa de UX própria;
- `pastescribe-cost-governor-review` — o gate de custo vive em `pastescribe-ai-cost-governance`; separar se a revisão de orçamento do admin ganhar procedimento próprio (Onda 3).

Não copiar regras de identidade, linguagem ou produto dos projetos de origem.
